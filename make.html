做卡入口

填好后生成客户专属链接。邮件里用「复制邮件卡片」粘贴即可；客户点卡会复制兑换码并跳转充值中心。

打开预览

邮件：点「复制邮件卡片」→ 写信窗口 Ctrl+V。若企微邮箱把链接剥掉，改用「下载 PNG」+「复制链接」，插图后选中图片加超链接。
聊天软件（TG / 微信 / Discord 等）：点「下载动图」发 GIF 好看，但动图本身不能跳转，必须再发一行兑换链接；或发 PNG + 链接。
「客户页语言」决定客户打开链接后看到的语言和卡面文字（默认 English），本页仍是中文。
「卡面主题」：默认 / 万圣节 / 圣诞节 / 万圣节·实体 / 圣诞节·实体 / 金卡 / 钻石卡；选了非默认主题，链接会带 &t=halloween / christmas / halloween2 / christmas2 / gold / diamond，客户页卡面同步。
链接格式：站点首页 + #n=名字&c=兑换码&a=金额&l=语言代码[&t=主题][&f=送卡人]（en / zh-CN / zh-TW / es / pt-BR / fr / de / ja / ko / ar / ru / uk）。兑换码只在链接里，不会写进仓库。
