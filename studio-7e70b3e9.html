客户页背景

客户打开链接时的全屏背景视频。默认「随机」；选定后写入链接 &b=，旧链接不带此参数仍随机。

兑换码

每行一个码 + 金额。可从表格一次性粘贴：多行码、或「码 + 金额」两列（Excel/Sheets 直接 Ctrl+V）。多码时卡面显示合计、码框模糊；发出去仍是一张卡 + 一条链接，客户页按张领取。

链接格式与发送说明

邮件：点「复制邮件卡片」→ 写信窗口 Ctrl+V。若企微邮箱把链接剥掉，改用「下载 PNG」+「复制链接」，插图后选中图片加超链接。
聊天软件（TG / 微信 / Discord 等）：动图好看但不能跳转，须再发一行兑换链接；或发 PNG + 链接。
单码 #n=名字&c=兑换码&a=$金额&l=语言[&t=主题][&f=送卡人][&b=背景]；多码 #n=…&c=CODE1:5,CODE2:10&a=$合计&l=…[&b=…]。b 可选：silk_flow / leaves_flow / feather_temple / diamond_hall / stardust_observatory / petal_greenhouse / neon_city / aurora_sea / courtyard_leaves / greek_temple_sunset / greek_amphitheater_moon / greek_colonnade_sea；省略则随机。兑换码只在链接里。
